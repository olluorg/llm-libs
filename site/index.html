Клиент API провайдера — звонит напрямую в OpenAI, Anthropic, Gemini и т. д. Шлюз — прокси к провайдерам (LiteLLM). Фреймворк — абстракция поверх SDK (LangChain, Pydantic AI). Локальный запуск — считает модель сам (Ollama, vLLM, transformers, llama.cpp); Ollama, vLLM и llama.cpp поднимают сервер, совместимый с openai-клиентом через base_url. Сопутствующее — векторные БД, наблюдаемость, eval, токенизаторы, UI, MCP.

Порядок по умолчанию — популярность = 2·log₁₀(звёзды) + log₁₀(счётчик реестра) + 0.5 за tier A. Счётчики приведены к логарифму, потому что величины несопоставимы: boto3 ставят 2.4 млрд загрузок в месяц, у crates.io счётчик накопительный, у Go — число импортов. Поэтому ★ и ⬇ можно сортировать отдельно: клик по заголовку.
